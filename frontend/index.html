What LexGuide AI does with your documents

  • Documents are processed locally by this application to extract text, detect clauses, and answer questions.
  • By default the AI provider is a fully offline, deterministic "Demo" engine — nothing leaves this server.
  • If an external AI provider is enabled by the operator, only clause excerpts relevant to a specific request are sent, never entire raw files, unless explicitly configured otherwise.
  • You can delete any single document, or all data, at any time below.
